UI mockups

Eight static screens for the redesigned MyOTA interface — four for administrators, four for participants. Both applications share one design system, stay responsive from 390 px upward, and respect light and dark colour schemes.

These are static mockups: no build step, no JavaScript framework, no network requests. They exist to fix layout and information density before implementation.

How to read these

Responsive. Resize the browser: below 780 px the admin sidebar collapses behind a toggle, and the participant navigation becomes a scrollable pill row. Table-heavy screens scroll horizontally rather than squashing.

Theme. Switch your OS between light and dark; every screen follows prefers-color-scheme with no separate assets.

Accessibility. Tables use real headers, the active nav item carries aria-current, form controls are labelled, and motion is disabled under prefers-reduced-motion.

Where the design comes from. Screen structure follows the service boundaries in the architecture document; the review screen mirrors the import pipeline in geodata-imports.md.
