MyOTA · design exploration

Four directions for the same two screens.

Identical content, identical information hierarchy, four deliberately different visual languages. Every one is responsive, themeable and built from a single self-contained stylesheet — no framework, no network request. The point is to choose a voice, not to pick the least boring default.

01

Editorial

Swiss typographic: a serif display against a grotesque, hairline rules, asymmetric grid, one vermillion accent. Reads like a considered report rather than a dashboard.

Display serif, italic
Accent vermillion
Density high, ruled
Shape square
