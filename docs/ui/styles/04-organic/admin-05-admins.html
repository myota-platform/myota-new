What this section cannot do

  • Verify a callsign. That is a support action and lives in Participants.
  • Delete an account. Deactivation is reversible; hard deletion is a retention job, not a button.
  • Remove its own last administrator role. The console cannot lock itself out.
  • Grant a scope the actor does not hold. Rejected at write time, whatever the interface allowed.
